# SmartStudy — MSIT 5910 capstone

A browser-based student assignment planner using HTML, CSS, JavaScript and browser localStorage.

## Run
Open `src/index.html` with a modern browser. No database, server or API is needed.

## Test
`node --test src/tests/*.test.js` (requires Node.js).

## Project structure
- `src/`: application code and automated tests
- `docs/`: requirements, report and evaluation notes
- `design/`: architecture blueprint and design assets

## Branches
`main` holds the baseline working version and design files; `development` contains additional evaluation tests. Git history is included in the ZIP to demonstrate the branch structure.

## Privacy
Use fictional tasks. Assignment data is held locally in the current browser and is not encrypted. No accounts, remote databases or private IDs should be added.
